# PDF 版面规范 v2（蓝白版式 · 2026-10-28 定稿）

> 本文件是 `gen_briefing_pdf_v2.py` 的行为说明书，也是交付验收标准。
> 任何改版式需求的落点都在脚本顶部的常量区，不要手工改 PDF、不要改 markdown 去凑版式。
>
> 定稿依据：2026-10-28 用户在 DSH 文档审阅页对 `20261028_A股晨间简报.pdf` 的两轮标记
> （第一轮：字号/编号/加粗/分块/精选 5 只/版面重设计；第二轮：深红金 → 蓝白、同章内容放一页）。

---

## 1. 页面与字体

| 项目 | 规格 | 脚本常量 |
|------|------|----------|
| 纸张 | A4 竖向 210×297mm | `PAGE_W / PAGE_H` |
| 页边距 | 左右 18mm、上 19mm、下 18mm | `MARGIN_LR / MARGIN_T / MARGIN_B` |
| 正文下界 | 268mm（正文不得越过） | `page_bottom` |
| 页脚线 | 271mm，0.2pt 浅灰；页码文字 272–279mm | `footer()` |
| 正文字体 | 宋体 `Songti SC Regular`（Songti.ttc face 6） | — |
| 粗体 | `Songti SC Bold`（face 1） | — |
| 正文字号 | **12pt（小四）**，行距 7.2mm，首行缩进 2 字 | `BODY_SIZE / BODY_LH` |
| 字体缓存 | `$BRIEFING_FONT_CACHE` → `~/.cache/a-share-briefing/fonts` → 系统临时目录 | `cache_dir()` |

> 字体从 `.ttc` 提取的原因：fpdf2 的 `add_font` 只认单一 face，Songti.ttc 默认取到的是
> face 0（Songti SC **Black**，笔画过重），必须用 fontTools 抽出 face 6（Regular）/ face 1（Bold）。
> 缓存文件各约 20MB，是正常大小；删掉后下次运行会自动重建（多花 5–8 秒）。

| 中蓝（序号 / 装饰线 / 目录序号） | `C_ACCENT` | `#306FA3` (48,111,163) |
| 浅蓝（底纹 / 强调块） | `C_SOFT` | `#E2ECF6` (226,236,246) |

| 正文墨色 | `C_INK` | `#1C1C1E` (28,28,30) |
| 次要灰 | `C_GREY` | `#6C7076` (108,112,118) |

## 3. 组件规格

### 3.1 封面（`draw_cover`）

```
[顶部居中短蓝线 1.6pt × 28mm]
        A 股 晨 间 简 报      31pt 深蓝 Bold，居中，y≈45mm
        2026年10月28日 星期三  13.5pt 灰，y≈70mm
   隔夜市场 · 昨日复盘 · 江浙沪动态 · 大涨股 · 今日关注   9.5pt 浅灰，y≈81mm
        本 期 目 录           12.5pt 深蓝 Bold + 浅蓝细分隔线，y≈105mm
   01  一、隔夜市场与重大新闻            P2     ← 序号中蓝 / 标题 13pt 墨色 / 页码深蓝
   02  二、昨日（10月27日）A股收盘回顾    P4
   …（5 条，行距 13mm，从 y≈122mm 起）
   ───────── 细分隔线 ─────────           y≈250mm
   本简报基于公开市场信息整理，不构成投资建议…  10pt 灰，**居中**
   数据时间截至 <从 markdown 自动提取> · 仅供参考  8.5pt 浅灰，居中
```

- **白底**，不用整版色块（用户嫌深色块"太正式"）。
- 目录页码 `Pn` 由**两遍渲染**得出（先渲染正文记录各章起始页，再画封面），必须真实。
- "数据时间截至"从 markdown 里正则提取 `数据时间截至\s*([^。，；;]+)`，提取不到只显示"仅供参考"。

### 3.2 章节标题（`chapter_title`）

- 18.5pt 深蓝 Bold，左侧 2.4×9mm 深蓝竖条，下接 0.7pt 中蓝分隔线
- 每个 `##` 一级标题**新起一页**

### 3.3 模块一：隔夜市场与重大新闻

- 每条自然段自动编号 `1、2、3……`（序号 12pt 深蓝 Bold，占据首行缩进位，正文从序号后接排）
- 正文 12pt，`（利好：…）` 深红、`（利空：…）` 深绿
- 编号由渲染器生成，**markdown 里不要手写序号**

### 3.4 模块三：省市投资动态

- `上海：` / `江苏：` / `浙江：` 开头的段落被拆成：省份小标题（15.5pt 深蓝 Bold + 2.2mm 竖条 + 浅蓝细线）+ 正文（11.5pt）
- 正文首行缩进 2 字

### 3.5 模块四：大涨股（每日精选 5 只）

每只股票渲染为一个块：

```
┃ 01  吉贝尔 (688566)   +20.63%          ← 竖条 + 序号 13.5pt 中蓝 + 名称 15pt Bold 墨色
   科创板 · 昨日涨20.63%收26.17元         ← 10.5pt 灰
   元数据  江苏镇江生物医药企业，总市值…    ← 标签 12pt 深蓝 Bold，正文 12pt
   判定    混合（预期先行）。依据：…
   事件    9月22日公告获得发明专利，…
```

- **元数据 / 判定 / 事件 三段各占独立段落**（用户明确要求"写完这段换行"）
- 解析规则：`名称(代码)，板块，昨日涨X%收Y元。【元数据】…【判定】…【事件】…`
- 精选数量：**每日 5 只**（2026-10-28 用户要求）；ST / 扣非为负 / 市值过小 / 机构缺位的垃圾股剔除，
  并在「剔除说明」段写明理由

### 3.6 模块五：今日关注与推荐

- 分组小标题识别规则：`^[^\s，：]{1,12}[：:]$`（即以「：」结尾的短行）→ 14pt 深蓝 Bold + 2.6mm 深蓝方块
  - 新股申购：/ 即将上市新股：/ 上涨潜力股：/ 优质股与业绩预增：/ 防御型与高股息标的：
- 个股段：行首 `名称(6位代码)` 自动加粗
- 正文 12pt

### 3.7 免责声明与页脚

- 免责声明：分隔线 + 9.5pt 灰，来源 `> ` 引用块
- 页脚：8pt 浅灰居中「A股晨间简报 · <日期> · 第 N/M 页」，上方 0.2pt 细线；封面不画页脚

## 4. 分页规则

1. **每章新起一页**（`##` = 一页起点）。
2. **章节自适应压排**（`best_scale_for_chapter`）：某章溢出时按 `0.96 → 0.92 → 0.88 → 0.84 → 0.80`
   逐级压缩 `line_h` 与段距，**字号不变**；能装进一页就装，压不进就用 1.0 正常跨页。
   - 下限 0.80 对应 12pt 字的 1.36 倍行距，是"可读底线"，不要再往下压。
   - 实测：模块二（昨日收盘回顾）在 0.92 下可整章一页；模块一（9 条新闻）与模块四/五内容量大，
     压到 0.80 仍跨页属正常。
3. **孤行控制**：段落若在页底只剩 1–2 行，整段移到下一页（不足 3 行就换页）。
4. **中文禁则**：`，。、；：？！）】》」』%` 等不得出现在行首——渲染器在换行时回溯搬移 token
   （连续多个禁则字符一并搬迁，最多 6 个）。
5. **超长 ASCII token**（如 `(688566)`）不被拆断；token 宽度超过行宽 90% 时退化为逐字断行。

## 5. 渲染器行为（写 markdown 前必读）

- 纯日期型 `##`（`## 2026年9月15日（星期二）`）与 `# ` H1 被跳过（封面已渲染日期，不会多空白页）
- `**` 不解析，按普通字符输出 —— markdown 里**不要写加粗标记**，粗体由版式规则决定
- emoji 不渲染，**不要用 emoji**
- 表格 `| a | b |` 渲染为「列头: 值 | 列头: 值」结构化文本
- `> ` 引用块 → 免责声明样式
- `### ` 子标题 → 13.5pt 深灰 Bold
- `- ` / `* ` 列表 → 项目符号段落（符号深蓝）

## 6. 交付自检（每次生成后必跑）

```bash
python3 ~/Desktop/TJU/dsh插件/Word文档+PDF实时预览/dsh-doc-preview/tools/pdf_audit.py <pdf> --expect-pages <页数>
```

必须达成：

| 检查项 | 期望 |
|--------|------|
| `fail` 计数 | **0**（无越界、无压叠、无缺失字号） |
| 文字压叠 | 未发现 |
| 字号 | 正文 12pt 为主要字号；标题 18.5/31pt 存在 |
| Type3 字体 | 0 |
| 页数 | 封面 + 各章页数；v2 早报通常 **10–12 页**（v1 为 6–8 页，页数变多是 12pt 正文的必然结果） |
| 内容完整性 | 股票代码、两位小数数值与源 md 集合比对 **零缺失** |
| 目录页码 | 封面 `Pn` = 各章实际起始页 |
| 行首禁则 | 0 处 |
| 页脚 | 第 N/M 页，M = 总页数 |

> 交付话术必须区分「已自动校验」（上述量化项）与「待人工目视」（蓝色打印深度、白底留白比例、
> 压排页与常规页行距差异的观感）。**不要把"几何校验通过"说成"没问题"。**

## 7. 版面红线

1. 正文宋体小四 12pt，**不得为了压页数缩字号**（只允许压行距，下限 0.80）。
2. 蓝白配色 + 红绿语义色，**不得恢复深红金**。
3. 模块一每条必须有编号；模块三省份名必须放大加粗；模块四大涨股必须分块（股票名加黑 + 元数据/判定/事件各起一行）；
   模块五分组小标题必须加粗 —— 这四项是用户逐条提过的，缺一条即返工。
4. 大涨股每日 5 只，垃圾股剔除并写明理由。
5. 目录页码、页脚总页数必须与实际页一致（两遍渲染保证，改脚本后要复核）。
6. 改版式只改脚本常量，**不改已交付的 PDF**，也不靠改 markdown 凑版式。
